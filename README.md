# WhatsApp Dispatcher Premium

> Powered by Synkra AIOX

## 🚀 Overview
Ferramenta moderna para automação e disparo de mensagens no WhatsApp com foco em UX/UI de alta qualidade e segurança (anti-ban).

## 🛠️ Tech Stack
- **Frontend**: Next.js 15, Vanilla CSS
- **Backend**: Node.js, Express, whatsapp-web.js
- **Real-time**: Socket.io

## 📂 Project Structure
- `.aiox/`: Configurações e metadados do framework AIOX.
- `docs/`: Documentação técnica, histórias de usuário e especificações.
- `backend/`: Servidor de integração com WhatsApp.
- `frontend/`: Interface administrativa.

## 📜 Methodology
Este projeto segue a metodologia **AIOX Story-Driven Development**.
Todas as implementações devem ser baseadas em histórias em `docs/stories/`.
