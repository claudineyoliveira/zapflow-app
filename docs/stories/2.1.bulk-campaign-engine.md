## Story
**As a** campaign manager,
**I want** to upload a list and send messages with smart delays and batches,
**so that** I can reach many people while avoiding WhatsApp bans.

## Acceptance Criteria
1. API accepts a list of contacts and global delay config (min/max/batch/pause).
2. Engine implements `setTimeout` with `Math.random()` variations between messages.
3. Engine pauses for X seconds after every Y messages.
4. Progress is emitted via Socket.io (current/total/fails).
5. A summary report is generated at the end.
