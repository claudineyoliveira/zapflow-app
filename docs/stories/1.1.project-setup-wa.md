## Story
**As a** developer,
**I want** to initialize the backend with `whatsapp-web.js` and local authentication,
**so that** I can maintain a persistent WhatsApp session.

## Acceptance Criteria
1. Backend initializes `whatsapp-web.js` with `LocalAuth`.
2. Backend emits `qr` event via Socket.io when needing authentication.
3. Backend emits `ready` event when authenticated.
4. Session data is stored in `.wwebjs_auth/` to persist logins.

## Testing
- **Manual**: Run `node index.js`, scan QR, restart server, verify it stays connected.
- **Logs**: Check terminal for "Client is ready!" without needing a new scan.
